# Assets et provenance

Les captures du showroom proviennent du checkout Azel à la révision indiquée dans IMAGE-PROVENANCE.json. Les entreprises des concepts sont fictives. Les visuels générés du Pilates sont des illustrations. Le nom Studio Lumière est un exemple de personnalisation.

Les quatre images publicitaires ont été générées pour cette demande. Leurs textes sont intégrés à l’image. Le code Remotion utilise des textes indépendants afin de conserver une typographie nette.

Les fichiers originaux de marque sont repris du projet Azel. Les SVG supplémentaires sont des éléments graphiques éditables basés sur sa géométrie existante.

Les polices Instrument Sans et Instrument Serif sont fournies avec les licences SIL Open Font License téléchargées depuis le dépôt Google Fonts.

Les quatre sons sont des créations synthétiques originales du pack. Aucune musique commerciale ni voix de tiers n’est fournie.

Les dépendances de développement gardent leurs licences respectives. La licence Remotion est disponible sur https://www.remotion.dev/license. Les informations de version et de reproduction figurent dans package-lock.json et VALIDATION.md.
