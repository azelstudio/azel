# Recettes pour enrichir le film

## Le carré devient une fenêtre

Dessiner le symbole avec deux éléments SVG. Agrandir la pièce principale en gardant son angle de référence. Révéler une capture dans le même masque. Le petit carré reste un repère graphique. Le passage de forme doit rester continu. Une succession d’un logo puis d’une fenêtre sans relation de position n’exprime pas la transformation.

Cette transition est une piste d’enrichissement pour Claude. La base incluse utilise une ouverture de signature, puis une arrivée de fenêtres en profondeur.

## Traverser le showroom

Conserver trois fenêtres avec profondeur distincte. Faire avancer la fenêtre choisie pendant que les autres s’éloignent et se désaturent légèrement. Son coin supérieur gauche devient l’ancrage de la scène suivante. Éviter les rotations qui rendent le contenu illisible.

## Cliquer une palette

Le curseur se déplace sur une courbe simple. Une pression courte confirme le clic. Le contour de sélection change. La bonne capture se remplace immédiatement et une légère lumière ponctue le changement. Le son est facultatif et synchronisé.

## Passage mobile

Le téléphone apparaît à côté du site, puis se place devant lui. L’image mobile provient d’un vrai viewport mobile. Ne pas recadrer la capture bureau pour fabriquer un faux responsive.

## Module tarif éventuel

Le master livré n’annonce aucun prix. Pour une version commerciale, préciser l’offre exacte et ses exclusions. Ne pas montrer une réservation, un paiement ou un site multipage avec une promesse qui concerne seulement la formule d’une page.
