# Production Azel

Ce dossier est un projet vidéo autonome. Le site Azel n’est pas une dépendance de rendu.

- Lire la direction et le storyboard avant de changer la composition.
- Conserver tous les fichiers média et les licences.
- Utiliser uniquement le temps Remotion pour les animations. Pas de Date.now, Math.random, setTimeout, CSS animation ou vidéo en iframe.
- Conserver la possibilité de rendre le film hors ligne après installation.
- Les effets audio fournis sont originaux. Pas de musique sous licence supposée.
- La copie principale n’annonce aucun prix pour éviter de mélanger création et frais de fonctionnement.
- Les captures montrent des concepts de showroom. Les personnes des visuels Pilates sont illustratives et ne constituent pas une affiliation avec un studio réel.
- `Studio Lumière` est un nom de démonstration utilisé dans les captures.
- Une interface de personnalisation mise en scène ne prouve pas qu’un CMS universel ou un portail client est disponible.
- Éviter les effets qui empêchent de lire le nom ou la transformation du site.
- Les titres et les boutons restent du texte rendu avec les polices locales. Les keyframes générées ne remplacent pas les calques du film.
- Vérifier les trois rapports d’image. Une version paysage demande une disposition propre, pas un recadrage du portrait.
- Les packages Remotion doivent garder exactement la même version entre eux.
- Conserver le fichier package-lock.json. Ne pas ajouter node_modules à une archive de livraison.
- Ne pas publier, acheter de publicité ou envoyer de messages.
